# Test

Cartella per i file di test.

- `GigaMeasureDisplay_selftest/` - variante del display GIGA con `SELFTEST` e `DEMO` attivi: la GIGA trasmette `CH1,5.000` su Serial1 per provare il link in loopback (D0-D1 ponticellati).
- `I2CScan/` - scansione di Wire e Wire1 per trovare gli indirizzi I2C (es. DFR1184 a 0x48/0x49).
